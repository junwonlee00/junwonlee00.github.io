# Template provenance

This personal website adapts Jon Barron's academic website template.

- Source repository: https://github.com/jonbarron/jonbarron.github.io
- Upstream commit: `25905bd773bd778585e66725780a7bc589269af1`
- Source HTML: https://github.com/jonbarron/jonbarron.github.io/blob/25905bd773bd778585e66725780a7bc589269af1/index.html
- Source CSS: https://github.com/jonbarron/jonbarron.github.io/blob/25905bd773bd778585e66725780a7bc589269af1/stylesheet.css
- Reuse statement: the upstream README invites cloning the code for personal use.

The original CSS is retained at the beginning of `stylesheet.css`, followed by
a small set of accessibility and mobile adjustments. `index.html` retains the
original centered 800px table layout and profile/contact structure, adapted for
Junwon Lee. The profile name uses a semantic `h1`.

Upstream personal text, papers, images, CV, custom-domain `CNAME`, and analytics
were not copied. The source was obtained from the GitHub repository, not from
the rendered website. The live page includes a link crediting the template.
